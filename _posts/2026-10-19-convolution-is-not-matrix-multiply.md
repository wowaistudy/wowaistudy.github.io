fallback 공부를 하다가 방향을 조금 틀었다. 보고서의 수백 층이 거의 다 Conv 층이라는데, Conv가 무슨 일을 하는지 모르고 있었다. CNN, CV, YOLO라는 단어도 실무에서 매일 듣는데 셋의 관계를 설명하지 못했다. 오늘은  Conv 하나만 봤다.

## 세 단어의 크기

```
CV    분야.  사진에서 뭔가를 알아내는 일 전체 (분류, 검출, 분할...)
CNN   도구.  그 일을 하는 모델 구조의 한 종류. 핵심 부품이 도장(커널)
YOLO  제품.  CNN으로 만든 검출 모델의 한 가족 이름
```

CV는 하는 일, CNN은 만드는 방법, YOLO는 그 방법으로 만든 특정 모델이다. "YOLO를 카메라에 올린다"는 말은 "CNN 구조의 검출 모델을 올린다"는 뜻이었다.

## 도장은 패턴 감지기다

격자 시리즈에서 도장은 "3×3 숫자 묶음을 이미지 위에 찍으며 미는 것"이었다. 그때는 어떻게 계산하나였고, 오늘은 왜 그걸 하나였다.

밝은 곳 1, 어두운 곳 0인 이미지 조각과, 세로선을 찾는 도장이다.

```
조각 A (세로선)      도장
  0 1 0             -1  2 -1
  0 1 0             -1  2 -1
  0 1 0             -1  2 -1
```

두 종이를 포개서 겹치는 칸끼리 곱하고, 아홉 개를 전부 더한다. 조각 A는 6이 나온다. 가로선 조각에 같은 도장을 찍으면 0이 나온다. 도장 안의 숫자가 찾고 싶은 모양이고, 결과값이 그 모양이 거기 있는 정도다. 이 숫자는 사람이 정하는 게 아니라 학습이 정한다. 양자화 글에서 "아주 조금씩 고치는 숫자"라고 했던 게 바로 이 도장 안의 숫자였다.

## 여기서 틀렸다

```
조각 C
  1 0 1
  1 0 1
  1 0 1
```

세로선이 아니니 음수가 나와야 할 것 같은데 계산하면 0이 나왔다. 식을 뜯어 보니 조각은 가로줄로 읽고 도장은 세로줄로 읽어서 짝을 짓고 있었다. 행렬 곱 습관이었다. 행렬 곱은 앞의 가로줄과 뒤의 세로줄을 곱하니까.

Conv는 그렇게 안 한다. 두 종이를 포개 놓고 **같은 위치 칸끼리** 곱한다. 1행 1열은 1행 1열과. 그렇게 하면 조각 C는 -6이다.

```
조각 C 1행:   1   0   1
도장   1행:  -1   2  -1
겹친 칸 곱:  -1   0  -1   →  -2      세 줄 합 -6
```

음수가 "없다"가 아니라 "정반대 모양이 있다"였다. 조각 C는 밝은 배경에 어두운 세로 틈이라 밝은 세로선의 정확한 반대다. 상관없는 모양이 0이다. 그리고 이 음수를 0으로 잘라 버리는 게 보고서에서 Conv 뒤에 항상 붙어 있던 ReLU였다. 내가 찾는 모양일 때만 값을 남긴다는 뜻이다.

## 합성곱이라는 게 따로 있었다

충격이었다. 행렬 곱 말고 다른 곱셈이 있는 줄 알았다. 그런데 새 곱셈은 아니었다. 곱셈과 덧셈은 똑같고, **어느 숫자와 어느 숫자를 짝짓느냐**만 다르다.

```
바닥 동작 하나:  두 숫자 묶음을 짝지어 곱하고 전부 더한다 (내적 = MAC가 하는 일)

행렬 곱:   앞의 가로줄  ↔  뒤의 세로줄       을 내적
합성곱:    이미지 조각   ↔  도장 (같은 자리)   을 내적
```

CNN은 거의 전부 합성곱이고, Transformer 계열은 거의 전부 행렬 곱이다. 둘 다 내적이라서 같은 격자 하드웨어로 돈다.

선형대수와의 관계도 하나로 정리됐다. 합성곱은 선형대수 바깥이 아니라 **모양이 특이한 행렬 곱**이다. 1차원으로 줄여서 보면 바로 보인다.

```
이미지 x1~x5, 도장 (a b c)를 한 칸씩 밀면

 [y1]     [a  b  c  0  0]   [x1]
 [y2]  =  [0  a  b  c  0] × [x2]
 [y3]     [0  0  a  b  c]   [x3]
                            [x4]
                            [x5]
```

행렬 곱인데 같은 숫자 세 개가 밀리면서 반복되고, 나머지는 0이다. "이웃만 본다"와 "같은 도장을 모든 자리에 쓴다"는 가정 두 개를 선형대수에 얹은 것이다. 이미지는 이 가정이 잘 맞아서 학습할 숫자가 엄청나게 줄어든다. 그게 이미지에 CNN을 쓰는 이유의 전부다.

그리고 격자 시리즈에서 지나갔던 "이미지를 조각 내서 일렬로 늘어놓아 행렬 곱으로 바꾼다"는 말이 그때는 무슨 소리인지 몰랐는데, 오늘 비로소 이해됐다. 위 식은 도장을 큰 행렬로 펼친 것이고, 그건 반대로 이미지 조각들을 늘어놓아 행렬로 만든 것이다. 어느 쪽으로 펼쳐도 행렬 곱이 된다.
